# حصن السعودي: تطبيق موبايل (PWA)

مدير ثروة ومصروفات شخصي: الذهب والشهادات والصناديق والزكاة (من الداشبورد الأصلية)، ومعاها حسابات ومعاملات يومية وميزانيات وفواتير متكررة وأهداف ادخار وديون وتقارير.

**البيانات على الجهاز بس** (`localStorage`). مفيش سيرفر ولا حساب. الريبو فيه الكود بس، ومفيهوش أي بيانات شخصية.

## الهيكل

| الملف | الوظيفة |
|---|---|
| `index.html` | هيكل التطبيق: 5 شاشات + شريط تنقل سفلي + زرار إضافة |
| `css/base.css` | ستايل الداشبورد الأصلي كما هو |
| `css/app.css` | ستايل الموبايل (تنقل، شيتات، قوائم، قفل) |
| `js/app.js` | محرك الحصن الأصلي (ذهب، صناديق، شهادات، زكاة، درجة الحصن، الإشارات) بعد إزالة اعتماده على Claude |
| `js/money.js` | الطبقة المالية الجديدة + النسخ الاحتياطي + القفل + التنقل |
| `js/pwa.js`, `sw.js`, `manifest.webmanifest` | التثبيت والعمل أوفلاين والتحديثات |

## التشغيل محليًا

```bash
cd hisn-app && python3 -m http.server 8080   # افتح http://localhost:8080
```

## الاستضافة (محتاج رابط https عشان يتثبت)

أي استضافة ملفات ثابتة مجانية تنفع، والمحتوى كله كود من غير بيانات:

- **Netlify Drop**: افتح app.netlify.com/drop واسحب فولدر `hisn-app`، وهتاخد رابط فورًا.
- **Cloudflare Pages**: اعمل مشروع جديد واختار رفع مباشر (Direct upload) للفولدر.

بعد كده افتح الرابط على الموبايل:
- **أندرويد (Chrome):** القائمة ⋮ ← «تثبيت التطبيق».
- **آيفون (Safari):** زرار المشاركة ← «إضافة إلى الشاشة الرئيسية».

## نقل بياناتك القديمة

من الإعدادات ⚙ ← «استرجاع نسخة» واختار ملف النسخة الاحتياطية (`.json`).

## إصدار جديد

غيّر الرقم في `js/version.js` و`VERSION` في `sw.js` مع بعض، والتطبيق المثبت هيعرض «نسخة جديدة جاهزة».

## سعر الذهب

بيجيب السعر العالمي (gold-api.com + open.er-api.com، وبعدهم currency-api كاحتياطي) ويحوّله لجنيه/جرام. بعد كده بيطبّق عليه علاوة السوق المحلي محسوبة من آخر سعر جلا اتكتب يدوي. لو مفيش معايرة بيعرض السعر العالمي ويوضح إنه بدون علاوة محلية.
